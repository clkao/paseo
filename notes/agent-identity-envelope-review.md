## What belongs in the first access-control release

Recommendations below are **inferred**. Source findings are **verified** at the cited lines in checkout `2c23cd492`. Paths starting with `agent/`, `authorization/`, `connected-hosts/`, or a bare TypeScript filename are relative to `packages/server/src/server/`.

| Part | Verdict | Reason |
|---|---|---|
| Credential | **Keep** | Issue a random bearer at every managed runtime launch, including unsandboxed launches. Resolve it to an agent and a launch generation. Reject conflicting identity claims, derive missing attribution, and retire existing sessions as well as tokens on release. An old socket must lose authority when the same agent ID resumes. |
| Immutable envelope | **Defer** | The user is the sole grant writer. A child starts with self access and zero cross-agent grants, so spawning cannot delegate authority. Exact grants can change while an agent runs. A frozen ceiling earns its cost when users need delegated, narrow-only tasks. |
| Grants store | **Merge** | Put a small list of exact sender, action and target triples in operator-owned daemon config. Consult current grants before each send. The first positive case needs one entry and one edit to revoke it. Defer a separate file, grant RPCs, selectors and app UI. |
| Decision function | **Keep** | Use one resource check on the resolved action and target, shared by CLI, HTTP MCP and native tools, before dispatch or side effects. Keep existing session permission checks. Admit only supported operations to agent sessions, including reads and subscriptions. A raw workspace, terminal or route permission exceeds a send grant. |
| Daemon-owned parentage | **Keep** | Stamp the parent address from the verified creator. Protect the two parent keys at caller-controlled write boundaries and preserve operator detach. Old labels can still describe the tree. Never use them as evidence of a grant. |
| Connected-host forwarding | **Defer** | Deny agent remote operations before either the MCP adapter or the SDK opens a route. This suffices for the third refusal. **Inferred — admission is the release boundary.** On every listener reachable by the agent, a missing, invalid or retired credential must fail before any anonymous or owner fallback. The smallest deployment can use a password-protected daemon and authenticated operator clients. To preserve anonymous operator access elsewhere, isolate that listener from agents. A shared passwordless listener cannot distinguish an operator from an agent that omits its identity. Give the agent CLI its issuing endpoint and private client state. Never send the bearer to an arbitrary selected host or retry as operator. Issue credentials everywhere and document that same-user secret access defeats isolation.
