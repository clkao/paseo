## Problem

The per-tab browser profile selector lists Shared and the current project's profiles. A user who wants to open a site with a profile owned by another project needs an explicit way to choose it.

## Proposed approach

Draft for later ideation. Consider a “Select from other project…” action on a new, never-navigated tab. It should identify the owning project and the selected profile before the first navigation.

## Acceptance criteria

To be written in ideation. The intended value is that a user can deliberately choose another project's profile and tell which profile the tab is using.

To be written in ideation.
